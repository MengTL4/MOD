# DICEOMANCER Cheat Menu（骰子浪游者内置修改器）

基于 BepInEx 6 (Unity Mono) + HarmonyX 的《骰子浪游者 / DICEOMANCER》游戏内修改器。

## 安装

1. 为游戏安装 BepInEx 6（Unity Mono 版本）。
2. 将编译得到的 `DICEOMANCER.dll` 放入 `游戏目录/BepInEx/plugins/`。
3. 启动游戏，按 **F9**（可在设置中修改）打开修改器窗口。

## 功能

| 页签 | 功能 |
| --- | --- |
| 常用功能 | 魔力不减、生命不减、伤害倍率（仅对敌人，1~10 倍）、金币模式（正常 / 金币不减 / 花费变获得）、卡牌能量种类无要求、卡牌自动强化、卡牌/遗物图鉴全解锁 |
| 当前卡组 | 查看当前卡组，每张卡可一键 **复制** 或 **删除**（删除需二次确认），支持按名称或编号搜索 |
| 卡牌图鉴 | 在游戏中打开卡牌图鉴后自动同步当前页，一键添加任意卡牌到卡组 |
| 遗物图鉴 | 在游戏中打开遗物图鉴后自动同步当前分类，单个获得或一键获得当前分类全部遗物 |
| 设置 | 修改快捷键、界面缩放、阻止点击穿透、恢复窗口位置、一键关闭全部功能 |

界面操作：

- 拖动标题栏移动窗口，拖动右下角调整窗口大小，位置和大小会自动保存。
- 所有开关状态都会保存到 `BepInEx/config/me.mengtl.plugin.cheatmenu.cfg`，下次启动游戏自动恢复。
- 窗口底部状态栏会提示每次操作的结果（例如“请先进入游戏对局”）。
- 如果游戏更新导致某个功能失效，该功能会显示“当前游戏版本不支持此功能”，其余功能不受影响。

## 编译

项目默认从 `..\..\Steam\steamapps\common\DICEOMANCER` 引用游戏与 BepInEx 的程序集。
游戏安装在其他位置时，可通过参数指定：

```
msbuild DICEOMANCER.csproj /p:Configuration=Release /p:GameDir="D:\SteamLibrary\steamapps\common\DICEOMANCER"
```

若游戏目录下存在 `BepInEx\plugins`，编译完成后会自动把插件复制过去。

## 更新日志

### 2.1.0

- 全新界面：深色主题、分页签布局、开关按钮、搜索框、状态栏提示、窗口可缩放/可调整大小。
- 卡组、图鉴列表中每一行直接提供操作按钮，不再需要手动输入编号。
- 所有开关与窗口设置持久化保存。
- 性能：卡组列表不再每次 OnGUI 都读取游戏数据（改为每 0.5 秒刷新一次）；图鉴名称本地化结果缓存；长列表只绘制可见行。
- 修复：卡牌自动强化在窗口打开时每帧对整副卡组重复调用强化。
- 修复：伤害倍率同时放大了玩家受到的伤害。
- 修复：“金币不减”和“金币不减反增”同时开启时互相抵消。
- 修复：输入无效编号、未进入对局时操作会抛出异常导致界面错乱。
- 修复：未进入对局（CardManager 不存在）时卡组面板每帧抛出空引用异常。
- 每个补丁独立应用，游戏更新后单个功能失效不会导致整个插件不可用。
- 鼠标在窗口上时阻止点击穿透到游戏界面（可在设置中关闭）。
