# MOD

我做的游戏 MOD，按游戏分目录存放。

| 游戏 | MOD | 类型 | 说明 |
|---|---|---|---|
| [Terminus: Zombie Survivors](Terminus-Zombie-Survivors/) | [AI 托管主角](Terminus-Zombie-Survivors/README.md) | Python 注入 | 一键让游戏自带的队友 AI 接管主角行动一回合，支持持续托管 |
| [骰子浪游者 DICEOMANCER](DICEOMANCER/) | [内置修改器](DICEOMANCER/CheatMenu/README.md) | BepInEx 6 | 魔力/生命不减、伤害倍率、金币模式、卡组编辑、卡牌/遗物图鉴等 |
| [Talented](Talented/) | [ModMenu](Talented/ModMenu/) | BepInEx 5 | 强制自动瞄准、天赋倍率、DLC 解锁 |
| [盖娅迷航 Gaia Trek](Gaia-Trek/) | [内置修改器](Gaia-Trek/CheatMenu/README.md) | BepInEx 6 | 无限攻击距离、超级攻速、资源/装备卡倍率、编辑资源与卡牌等 |

DICEOMANCER、Talented、Gaia Trek 三个 MOD 原先是独立仓库（DICEOMANCERCheatMenu、TalentedModMenu、GaiaTrekCheatMenu），已连同提交历史合并到这里。
