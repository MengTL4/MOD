# MOD

我做的游戏 MOD，按游戏分目录存放。

| 游戏 | MOD | 类型 | 说明 |
|---|---|---|---|
| [Terminus: Zombie Survivors](Terminus-Zombie-Survivors/) | [AI 托管主角](Terminus-Zombie-Survivors/ai_takeover/README.md) | Python 注入 | 一键让游戏自带的队友 AI 接管主角行动一回合，支持持续托管 |
| [Terminus: Zombie Survivors](Terminus-Zombie-Survivors/) | [队伍背包共享](Terminus-Zombie-Survivors/shared_inventory/README.md) | Python 注入 | 主角和队友的背包合并成一个，制作、烹饪、用药、队友 AI 都从全队物品里找 |
| [Terminus: Zombie Survivors](Terminus-Zombie-Survivors/) | [队友 AI 加强](Terminus-Zombie-Survivors/companion_ai/README.md) | Python 注入 | 队友低血量撤退、按期望伤害选部位/武器/目标、集火、不乱开枪、互相治疗、护卫、捡弹药和药品 |
| [Terminus: Zombie Survivors](Terminus-Zombie-Survivors/) | [LemonCitrine 全系列 MOD 汉化](Terminus-Zombie-Survivors/lemon_mods_zh/README.md) | 翻译（官方数据 MOD） | 创意工坊作者 LemonCitrine 所有 MOD 的简体中文翻译合集 |
| [骰子浪游者 DICEOMANCER](DICEOMANCER/) | [内置修改器](DICEOMANCER/CheatMenu/README.md) | BepInEx 6 | 魔力/生命不减、伤害倍率、金币模式、卡组编辑、卡牌/遗物图鉴等 |
| [Talented](Talented/) | [ModMenu](Talented/ModMenu/) | BepInEx 5 | 强制自动瞄准、天赋倍率、DLC 解锁 |
| [盖娅迷航 Gaia Trek](Gaia-Trek/) | [内置修改器](Gaia-Trek/CheatMenu/README.md) | BepInEx 6 | 无限攻击距离、超级攻速、资源/装备卡倍率、编辑资源与卡牌等 |

DICEOMANCER、Talented、Gaia Trek 三个 MOD 原先是独立仓库（DICEOMANCERCheatMenu、TalentedModMenu、GaiaTrekCheatMenu），已连同提交历史合并到这里。
