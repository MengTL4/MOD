# 队伍背包共享 MOD

主角和所有队友的背包合并成一个大背包。

## 效果

- 打开任何人的背包，都能看到、使用、丢弃全队的物品。自己的物品排在前面。
- 制作、烹饪、修理、用药、生火、加固、灌水、任务交物品等所有「从身上找东西」的地方都会用到全队物品。
- 队友 AI（以及 AI 托管 MOD 控制的主角）吃喝、用药、制作、读书、修理时同样从全队物品里找。
- 物品被消耗、丢弃、交出时，从真正携带它的人身上扣除，不会复制物品。
- 队友携带的物品，格子左上角显示持有者名字的首字（每人一种颜色；一叠物品分属多人时显示「+」）。
  鼠标停在上面，提示里会写「在 XX 身上」，混装的一叠会写「携带者：你 ×2 · XX ×1」。
- 背包面板下方有「显示：全队物品 / 只看自己」切换按钮（快捷键 V），选择会被记住。
  「只看自己」时列表和负重一致；制作、烹饪等界面和队友 AI 仍然使用全队物品。

**不共享的东西**：

- 队友身上穿着的衣服和背包、正在用的铺盖。
  去穿队友包里的衣服时，会先把衣服转到自己身上再穿。
- 「带在身上就生效」的被动效果：手电照明、雨伞和雨具防水、持械等级、米娜的指南针（移动省 AP）、内森的笔记本（药效 ×1.2）、「宝物猎人」成就的珠宝计数。
  在背包里对队友的手电点「使用」时，会先把手电拿到自己身上再打开；动作面板的「开灯」只用自己身上的灯。
- 负重：各算各的，捡到的东西进捡的人背包。

**和队友交换物品**：库存界面右侧是队友时，双方显示各自的真实背包，方便调配负重。

**注意**：背包界面的「全部丢下」会丢下合并背包里的所有物品，包括队友身上可共享的那些。

**回合卡住保护**：结束回合时如果出现任何错误，原版会一直停在「其他幸存者的回合」转圈。
本 MOD 会在记录错误后把控制权交还玩家，主角头顶提示「回合结算出错，已恢复」。

## 配置

编辑 `shared_inventory.py` 开头的常量，改完重启游戏生效：

- `SAME_LOCATION_ONLY`：`True` 表示只和同一地图上的队友共享，默认 `False`（全队共享）。
- `OWNER_TOOLTIP`：是否在物品提示里显示携带者。
- `OWNER_BADGE`：是否在队友的物品格子上显示持有者角标。
- `VIEW_HOTKEY`：「全队物品 / 只看自己」切换快捷键，默认 `v`。

## 安装 / 卸载

- 安装：双击 `install.bat`（需要 Python 3.12，脚本会自动用 uv 或 py 启动器）。
- 卸载：双击 `uninstall.bat`。如果 AI 托管等其他 MOD 还在，只会停用本 MOD（生成 `DISABLED` 文件），
  然后删除本文件夹即可；否则会还原 `base_library.zip`。也可以在 Steam 里「验证游戏文件完整性」。
- **游戏更新后**：Steam 会覆盖 `base_library.zip`，MOD 会失效，重新运行一次 `install.bat` 即可。
- 存档里保存的仍然是每个人自己的背包，卸载 MOD 后存档照常可用。

## 原理

游戏是 PyInstaller 打包的 Python 3.12 程序。安装脚本把 `_internal\base_library.zip` 里的标准库
`linecache.pyc` 换成「先原样执行原字节码，再装一个 MOD 加载器」的版本。加载器会加载游戏目录下所有
`<名字>\<名字>.py` 形式的 MOD，和主角 AI 托管 MOD 共用。

本 MOD 替换了 `Character.items` 属性：对主角和队友返回一个合并视图列表（`SharedItems`）。

- 读：看到全队物品。
- `remove`、`batch_remove`、`pop`：转发到物品真正所在的人。
- `append`、`extend`、`+=`：加到自己身上。
- 整体赋值 `char.items = [...]`：按「合并背包变成这个列表」处理差异。

以下游戏函数需要只看自己身上的物品，按调用方判断，仍然拿到原始列表（见 `RAW_FUNCS`）：

- 负重和背包整理
- 死亡掉落
- 每回合物品结算（腐败、刷新等，避免重复处理）
- 穿戴
- 照明、防水
- 计分
- NPC 扒窃

另外修正了 `Item.get_storage`，让它先在队员的原始背包里找物品的真正持有者。

## 排错

出错时游戏不会崩溃，错误写在本目录的 `shared_inventory.log`。正常启动后日志应有：

```
队伍背包共享 MOD 已加载
已修正物品归属查询
已设置使用队友的灯时先拿到自己身上
已替换 Character.items 为合并背包
已添加结束回合出错恢复
已设置开灯只用自己身上的灯
已添加物品携带者提示和角标
已设置队友交换界面
```

如果日志文件根本没生成，说明加载器没生效：运行 `install.py --status` 看状态。
