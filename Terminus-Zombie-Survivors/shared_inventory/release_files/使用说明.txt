Terminus: Zombie Survivors - 队伍背包共享 MOD（非官方）
=====================================================

主角和所有队友的背包合并成一个大背包。

【为什么要手动安装】
游戏的创意工坊模组只支持数据（JSON/图片），不会执行代码。本 MOD 需要运行一次安装程序，
订阅后游戏内模组管理器里的开关对它无效，以下面的安装 / 卸载为准。

【安装】（不需要装 Python）
◆ 从创意工坊订阅的：
  1. 订阅后等 Steam 下载完成，先退出游戏。
  2. 打开 MOD 下载目录：
       <你的 Steam 库>\steamapps\workshop\content\1534980\__ITEM_ID__
     最快的找法：在游戏目录（Steam 库里右键游戏 → 管理 → 浏览本地文件）向上退两级到 steamapps，
     再进 workshop\content\1534980，里面带 install.bat 的那个文件夹就是。
  3. 双击 install.bat，看到“安装完成”即可。
◆ 下载压缩包的：解压到任意位置，双击 install.bat。

安装程序会自动找到游戏（找不到会弹窗让你选游戏目录），把 MOD 复制到 <游戏目录>\shared_inventory，
并先校验游戏版本，不匹配就不会改动任何游戏文件。

【效果】
- 打开任何人的背包都能看到、使用、丢弃全队的物品，自己的物品排在前面。
- 制作、烹饪、修理、用药、生火、加固、灌水、任务交物品等所有「从身上找东西」的地方都会用到全队物品。
- 队友 AI（以及「AI 托管主角」MOD 控制的主角）吃喝、用药、制作、读书、修理时同样从全队物品里找。
- 物品被消耗、丢弃、交出时，从真正携带它的人身上扣除，不会复制物品。
- 队友携带的物品，格子左上角显示持有者名字的首字；鼠标停在上面，提示里会写「在 XX 身上」
  （一叠物品分属几个人时写「携带者：你 ×2 · XX ×1」）。
- 背包面板下方有「显示：全队物品 / 只看自己」切换按钮（快捷键 V），选择会被记住。
  「只看自己」时列表和负重一致；制作、烹饪和队友 AI 仍然用全队物品。
- 和队友交换物品的界面（库存界面右边是队友）里，双方显示各自的真实背包，方便调配负重。

不共享的东西：
- 队友穿着的衣服和背包、手持的武器、正在用的铺盖。穿队友包里的衣服时会先转到自己身上。
- 「带在身上就生效」的效果：手电照明、雨伞和雨具防水、持械等级。
  在背包里对队友的手电点「使用」时，会先把手电拿到自己身上再打开。
- 负重：各算各的，捡到的东西进捡的人背包。

注意：背包界面的「全部丢下」会丢下当前显示的所有东西——「全队物品」时包括队友身上的物品，
「只看自己」时只丢自己身上的。

回合卡住保护：结束回合时如果出现任何错误，原版会一直停在「其他幸存者的回合」转圈；
本 MOD 会在记录错误后把控制权交还玩家，主角头顶提示「回合结算出错，已恢复」。

【设置】
用记事本打开 <游戏目录>\shared_inventory\shared_inventory.py，改开头几项，重启游戏：
  SAME_LOCATION_ONLY = True   只和同一地图上的队友共享（默认 False：全队共享）
  OWNER_TOOLTIP = False       不在物品提示里显示携带者
  OWNER_BADGE = False         不在队友的物品格子上显示持有者角标
  VIEW_HOTKEY = "v"           「全队 / 只看自己」切换快捷键

【MOD 更新后】
创意工坊更新了 MOD 后，再双击一次 install.bat，把新文件复制进游戏。

【游戏更新后】
Steam 更新游戏可能会还原被修改的文件，导致 MOD 失效，再双击一次 install.bat 即可。
如果提示“Python 运行库不匹配”，说明游戏升级了内置 Python，需要等 MOD 更新。

【卸载】
双击 uninstall.bat（删除 <游戏目录>\shared_inventory；没有其他 MOD 在用时游戏会恢复原样），然后取消订阅。
存档里保存的仍然是每个人自己的背包，卸载后存档照常可用。

【原理与说明】
安装程序只修改一个文件：<游戏目录>\_internal\base_library.zip 里的 Python 标准库 linecache.pyc，
换成“原样执行原代码 + MOD 加载器”的版本。MOD 加载器与「AI 托管主角」等 MOD 共用，
可以同时安装；安装包自带原始文件，最后一个 MOD 卸载时用它还原。
MOD 源码（shared_inventory.py）是明文，可以直接查看。单机游戏。
出错时游戏不会崩溃，错误写在 <游戏目录>\shared_inventory\shared_inventory.log，反馈问题时请附上。
