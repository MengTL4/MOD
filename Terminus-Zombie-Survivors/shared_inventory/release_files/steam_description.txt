[h1]队伍背包共享 —— 全队一个大背包[/h1]

主角和所有队友的背包合并成一个大背包。打开任何人的背包都能用全队的物品；做饭、制作、修理、用药时不用再来回倒腾东西，队友 AI 也会从全队物品里找吃的、药和材料。

[b]⚠ 游戏每次更新后本 MOD 都会失效：退出游戏，再双击一次 install.bat 就能恢复。[/b]

[h2]⚠ 需要手动安装（订阅后不会自动生效）[/h2]
游戏的创意工坊模组只支持数据（JSON/图片），不会执行代码，所以本 MOD 需要运行一次安装程序。[b]游戏内模组管理器里的开关对本 MOD 无效。[/b]

[list]
[*]订阅本 MOD，等 Steam 下载完成，[b]退出游戏[/b]。
[*]打开 MOD 下载目录：[b]<你的 Steam 库>\steamapps\workshop\content\1534980\__ITEM_ID__[/b]
  找法：Steam 库里右键游戏 → 管理 → 浏览本地文件，向上退两级到 steamapps，再进 workshop\content\1534980。
[*]双击 [b]install.bat[/b]，看到“安装完成”就行。[b]不需要安装 Python。[/b]
[/list]
安装程序会自动找到游戏目录（找不到会弹窗让你选），把 MOD 复制到 <游戏目录>\shared_inventory，并先校验游戏版本——不匹配就不会改动任何游戏文件。

[h2]效果[/h2]
[list]
[*]打开任何人的背包都能看到、使用、丢弃全队的物品，自己的物品排在前面。
[*]制作、烹饪、修理、用药、生火、加固、灌水、任务交物品等所有「从身上找东西」的地方都会用到全队物品。
[*]队友 AI（以及 [b]AI 托管主角[/b] MOD 控制的主角）吃喝、用药、制作、读书、修理时同样从全队物品里找。
[*]物品被消耗、丢弃、交出时，从真正携带它的人身上扣除，[b]不会复制物品[/b]。
[*]队友携带的物品，格子左上角显示持有者名字的首字；鼠标停在上面，提示里写「在 XX 身上」（混装的一叠写「携带者：你 ×2 · XX ×1」）。
[*]背包面板下方有 [b]「显示：全队物品 / 只看自己」[/b] 切换按钮（快捷键 V），只看自己时列表和负重一致。
[*][b]回合卡住保护[/b]：结束回合时如果出错，记录错误后把控制权交还玩家，不会卡在「其他幸存者的回合」。
[*]和队友交换物品的界面里，双方显示各自的真实背包，方便调配负重。
[/list]

[b]不共享的东西[/b]：队友穿着的衣服和背包、正在用的铺盖（穿队友包里的衣服时会先转到自己身上）；手电照明、雨具防水、米娜的指南针、内森的笔记本这类“带在身上就生效”的效果（在背包里使用队友的手电时会先拿到自己身上）；负重——各算各的，捡到的东西进捡的人背包。
[b]注意[/b]：背包界面的「全部丢下」会丢下当前显示的所有东西——「全队物品」时包括队友身上的物品，「只看自己」时只丢自己的。

[b]设置[/b]：用记事本打开 <游戏目录>\shared_inventory\shared_inventory.py，把 SAME_LOCATION_ONLY 改成 True 就只和同一地图上的队友共享。

[h2]更新 / 卸载[/h2]
[list]
[*][b]MOD 更新或游戏更新后[/b]：再双击一次 install.bat。若提示“Python 运行库不匹配”，说明游戏升级了内置 Python，请等待 MOD 更新。
[*][b]卸载[/b]：双击 uninstall.bat（没有其他 MOD 在用时游戏恢复原样），再取消订阅。存档里保存的是每个人自己的背包，卸载后存档照常可用。
[/list]

[h2]原理[/h2]
安装程序只修改一个文件：<游戏目录>\_internal\base_library.zip 里的 Python 标准库模块 linecache.pyc，换成“原样执行原代码 + MOD 加载器”的版本；安装包自带原始文件，卸载时用它还原。MOD 加载器与 [b]AI 托管主角[/b] 等 MOD 共用，可以同时安装。MOD 源码（shared_inventory.py）是明文，可以直接查看。单机游戏。出错时游戏不会崩溃，错误写在 <游戏目录>\shared_inventory\shared_inventory.log，反馈问题请附上。

非官方 MOD，与开发商无关。

[h1]Shared Party Inventory[/h1]
Your character's and all companions' inventories become one shared pool. Any inventory screen shows the whole party's items, crafting/cooking/repairs/medicine use them, and the companion AI eats, heals and crafts from the shared pool too. Used items are taken from whoever actually carries them - nothing is duplicated.

[b]⚠ Every game update turns this mod off: quit the game and run install.bat again.[/b]

[h2]⚠ Manual install required[/h2]
Workshop mods for this game can only contain data, so the game never runs this mod by itself, and its switch in the in-game mod manager does nothing.
[list]
[*]Subscribe, wait for the download, [b]quit the game[/b].
[*]Open [b]<Steam library>\steamapps\workshop\content\1534980\__ITEM_ID__[/b].
[*]Double-click [b]install.bat[/b]. No Python needed. It finds the game, copies the mod to <game>\shared_inventory and checks the game version first.
[/list]

[h2]Details[/h2]
Not shared: clothes/bags a companion is wearing, bedding in use, passive carried effects (flashlight light, rain gear, MINA's compass, NATHAN's notebook), and weight - everyone carries their own. Companions' items show the carrier's initial on the slot, and hovering shows who carries it. A "party / mine only" toggle (hotkey V) below the inventory panel lists just your own items. If ending a turn ever errors, the mod hands control back to you instead of spinning forever. In the companion trade screen both sides show their real inventory. "Drop all" drops the whole shared pool. Set SAME_LOCATION_ONLY = True in shared_inventory.py to share only with companions on the same map.

[h2]Update / uninstall[/h2]
After a mod or game update, run install.bat again. To remove, run uninstall.bat, then unsubscribe. Saves load normally without the mod.
The installer changes only linecache.pyc inside <game>\_internal\base_library.zip (a small mod loader shared with other mods such as AI Takeover) and ships the original to restore it. Works together with AI Takeover. Unofficial mod.
