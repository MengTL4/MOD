# 主角 AI 托管 MOD

让游戏自带的队友 AI 接管主角，一键托管一回合，也可以持续托管。

## 用法

动作面板（右下角）里多了一个机器人图标的按钮：

| 操作 | 效果 |
|---|---|
| 左键按钮 / `F6` | AI 控制主角行动一回合，行动完自动结束回合 |
| `Shift+F6` | 开启持续托管：每个玩家回合自动托管 |
| 持续托管中点按钮 / 按 `F6` | 停止持续托管 |
| 右键按钮 | 菜单：托管本回合 / 开关持续托管 / AI 行为设置 |

**AI 会做什么**（和队友 AI 完全相同的逻辑与优先级）：
用药治疗 → 睡觉（附近无威胁且精力不足时）→ 攻击僵尸/敌对 NPC → 修车 → 清理障碍 →
搜刮家具、捡有价值的物品 → 继续升级/制作 → 读书 → 听音乐 → 缝补衣物 → 修理电子产品/工具 →
种田 → 最后按需吃喝。

不会做的：换地图、开车、和 NPC 对话交易等需要玩家决策的事。

**AI 行为设置**：右键菜单里打开的是游戏原生的「队友自动化设置」面板，只对主角生效，
可以单独开关攻击、搜尸体、吃生肉/变质食物、喝脏水、睡觉、读书、种田、捡物品的价值/重量阈值等。
活动范围选项：跟随 = 以自己为中心 20 格内，靠近 = 5 格内，原地 = 整个区域。
面板顶部的总开关对主角无效，忽略即可。

持续托管时，主角 HP 低于 35% 会自动停止；有弹窗（升级、对话等）时会暂停等你处理。

## 配置

编辑 `ai_takeover.py` 开头的几个常量：快捷键 `HOTKEY`、持续托管停止的 HP 比例
`CONTINUOUS_STOP_HP_RATIO`、每回合接管前的等待时间 `CONTINUOUS_DELAY`。改完重启游戏生效。

## 安装 / 卸载

- 安装：双击 `install.bat`（需要 Python 3.12，脚本会自动用 uv 或 py 启动器）
- 卸载：双击 `uninstall.bat`，或在 Steam 里「验证游戏文件完整性」
- **游戏更新后**：Steam 会覆盖 `base_library.zip`，MOD 会失效，重新运行一次 `install.bat` 即可
- 安装前的原始文件备份在 `backup\base_library.zip.orig`

## 原理

游戏是 PyInstaller 打包的 Python 3.12 程序，官方 Workshop 只支持 JSON 数据补丁，不能加代码。
安装脚本把 `_internal\base_library.zip` 里的标准库 `linecache.pyc` 换成「先原样执行原字节码，
再装一个 MOD 加载器」的版本；加载器加载游戏目录下所有 `<名字>\<名字>.py` 形式的 MOD
（本 MOD、队伍背包共享 MOD 等共用），游戏加载动作面板 / 主场景时调用 `ai_takeover.py`
给游戏类打补丁。原 `linecache` 的行为完全不变，卸载时从补丁里取回原字节码还原；
如果还有其他 MOD 在用加载器，卸载只会停用本 MOD（在本目录生成 `DISABLED` 文件）。

## 排错

出错时游戏不会崩溃，错误写在本目录的 `ai_takeover.log`。正常启动后日志应有：

```
AI 托管 MOD 已加载
已为动作面板添加 AI 托管按钮
已注册快捷键 F6
```

如果日志文件根本没生成，说明引导代码没生效：先在本目录运行 `install.bat` 看状态，
或执行 `install.py --status`。
