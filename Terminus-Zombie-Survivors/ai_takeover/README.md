# 主角 AI 托管 MOD

让游戏自带的队友 AI 接管主角，一键托管一回合，也可以持续托管。

## 用法

动作面板（右下角）里多了一个机器人图标的按钮：

| 操作 | 效果 |
|---|---|
| 左键按钮 / `F6` | AI 控制主角行动一回合，行动完自动结束回合 |
| `Shift+F6` | 开启持续托管：每个玩家回合自动托管 |
| 持续托管中点按钮 / 按 `F6` | 停止持续托管 |
| 右键按钮 | 菜单：托管本回合 / 开关持续托管 / AI 行为设置 |
| AI 行动中点按钮（停止图标）/ 按 `F6` / `Esc` | 立即停止托管：本回合不结束，剩下的 AP 留给你手动用，持续托管也一并关闭 |

**AI 会做什么**（和队友 AI 完全相同的逻辑与优先级）：
用药治疗 → 睡觉（附近无威胁且精力不足时）→ 攻击僵尸/敌对 NPC → 修车 → 清理障碍 →
搜刮家具、捡有价值的物品 → 继续升级/制作 → 读书 → 听音乐 → 缝补衣物 → 修理电子产品/工具 →
种田 → 最后按需吃喝。

不会做的：换地图、开车、和 NPC 对话交易等需要玩家决策的事。

**AI 行为设置**：右键菜单里打开的是游戏原生的「队友自动化设置」面板，只对主角生效，
可以单独开关攻击、搜尸体、吃生肉/变质食物、喝脏水、睡觉、读书、种田、捡物品的价值/重量阈值等。
活动范围选项：跟随 = 以自己为中心 20 格内，靠近 = 5 格内，原地 = 整个区域。
面板顶部的总开关对主角无效，忽略即可。

持续托管时，主角 HP 低于 35% 会自动停止；有弹窗（升级、对话等）时会暂停等你处理。

**托管期间的弹窗**：托管回合跑在玩家回合里，玩家输入是关着的。原版有一批只在玩家回合才弹的窗口
（工具碎裂、读完书获得技能/属性、学会配方、“要重读书籍吗？”、升级选技能），托管时弹出来点不掉。
所以托管期间普通提示改为头顶飘字（全文写进日志）；重读和队友 AI 一样直接从头读
（原版此时只弹确认框不重置进度，AI 会 0 AP 反复“读完”同一本书、白拿属性/技能）；
升级选技能等托管回合结束、没有其他弹窗时再弹。

**立即停止**：AI 行动时机器人按钮会变成方块停止图标，托管中只有它能点。点下后 AI 在下一个能安全停下的地方
（等动画、两次寻路之间、两个任务之间）停手，正在播的走路 / 动作动画放完后交还操作；
3 秒内还停不下来就强制中止。结束回合阶段（队友、僵尸行动）不能打断，这时按 `F6` 只会关掉持续托管。

**铁丝网**：原版队友 AI 寻路时只把铁丝网当成“不能斜穿”，近战去打网另一边的僵尸时会走到网边、
停在僵尸前一格，隔着网打不到；搜刮途中每走一步又被“遇敌”拉回网边，来回跑到 AP 用完。
托管主角用近战武器攻击时把完好的铁丝网当成墙：打不到的僵尸直接跳过（它也过不来），
绕得过去的照常绕过去打；远程武器隔网能打，不受影响。另外原版寻路按步数算，翻一次网（10 AP，跑酷 5）也只算一步，
托管主角的路线要翻网时，会改走实际 AP 更少的绕行路线。

**卡住保护**：AI 行动时主角的 AP、位置、物品、耐久、士气 40 秒都没变化，就向 AI 线程注入异常中止本回合托管，
关闭持续托管并交还操作（本回合不结束），同时把所有线程的调用栈写进日志。结束回合（队友 / NPC / 僵尸行动）
中途出异常时，原版会一直停在“不能操作”，这里会把回合交还给玩家。结束回合超过 90 秒也会记录调用栈。

**画面卡顿**：托管回合内把 Python 线程切换间隔从 5 毫秒调到 0.5 毫秒（回合结束后恢复），
AI 线程算路径时不容易把渲染线程饿住。托管中一帧超过 0.2 秒会把 AI 当时在做什么写进日志（每次启动最多 10 条），
遇到卡顿请附上 `ai_takeover.log`。

## 配置

编辑 `ai_takeover.py` 开头的几个常量：快捷键 `HOTKEY`、持续托管停止的 HP 比例
`CONTINUOUS_STOP_HP_RATIO`、每回合接管前的等待时间 `CONTINUOUS_DELAY`、卡住判定时间 `STALL_TIMEOUT`、点停止后强制中止的等待 `STOP_GRACE`、
托管时的线程切换间隔 `AI_SWITCH_INTERVAL`（0 = 不调整）、卡顿记录门槛 `HITCH_LOG`（0 = 不记录）。改完重启游戏生效。

## 安装 / 卸载

- 安装：双击 `install.bat`（需要 Python 3.12，脚本会自动用 uv 或 py 启动器）
- 卸载：双击 `uninstall.bat`，或在 Steam 里「验证游戏文件完整性」
- **游戏更新后**：Steam 会覆盖 `base_library.zip`，MOD 会失效，重新运行一次 `install.bat` 即可
- 安装前的原始文件备份在 `backup\base_library.zip.orig`

## 原理

游戏是 PyInstaller 打包的 Python 3.12 程序，官方 Workshop 只支持 JSON 数据补丁，不能加代码。
安装脚本把 `_internal\base_library.zip` 里的标准库 `linecache.pyc` 换成「先原样执行原字节码，
再装一个 MOD 加载器」的版本；加载器加载游戏目录下所有 `<名字>\<名字>.py` 形式的 MOD
（本 MOD、队伍背包共享 MOD 等共用），游戏加载动作面板 / 主场景时调用 `ai_takeover.py`
给游戏类打补丁。原 `linecache` 的行为完全不变，卸载时从补丁里取回原字节码还原；
如果还有其他 MOD 在用加载器，卸载只会停用本 MOD（在本目录生成 `DISABLED` 文件）。

## 排错

出错时游戏不会崩溃，错误写在本目录的 `ai_takeover.log`。正常启动后日志应有：

```
AI 托管 MOD 已加载
托管期间的弹窗改为飘字
托管主角近战时绕开铁丝网；托管中可随时停止
已为动作面板添加 AI 托管按钮
已注册快捷键 F6（托管中 F6 / Esc 立即停止）
```

如果日志文件根本没生成，说明引导代码没生效：先在本目录运行 `install.bat` 看状态，
或执行 `install.py --status`。
