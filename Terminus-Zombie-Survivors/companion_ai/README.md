# 队友 AI 加强 MOD

在游戏自带的队友 AI 上替换几个决策点，其余行为保持原版。AI 托管 MOD 控制主角时同样生效。
尊重游戏原生的「队友自动化设置」：攻击开关、是否用枪、是否使用医疗用品、是否拾取物品、移动方式等。

## 战斗：回合规划

原版的队友战斗是一串固定规则：打最近的、用面板伤害最高的武器、永远打头、走过去后剩不到 5 AP 就停下等。
本 MOD 换成一个按游戏真实规则算账的规划器。

### 僵尸的规则（从游戏代码里读出来的）

- 僵尸追**最近**的人，沿最短路走；路线下一格有人就原地攻击，直到 AP 用完，每次攻击 1 AP。
- 只能从**上下左右**相邻的格子攻击（斜角不能打）。
- 行动力 = `max_action × 腿剩余血量比例`，腿打断了只能爬（行动力 × 0.4，攻击力减半）。
- 攻击力 = `max_attack × 躯干剩余血量比例`；**躯干打到 0 的僵尸不能抓伤、也不能擒抱**。
- 每次攻击随机挑一种：
  - 没流血：抓伤、抓伤、（人还有 AP 时）擒抱。擒抱扣 AP 不扣血。
  - 流血：只有擒抱。
  - **流血且 AP 为 0：咬，没有感染抗性就直接死。**
- 对玩家角色的伤害 = `攻击力 × 0.9~1.1 − 衣物防御`，最低 0。衣物没有部位限制，总负重不到 10 就能叠穿，防御相加。
- 闪避率 = 敏捷 × 8%。AP 每回合按体质恢复约 10 点，用不完的攒到下回合（上限一般 20）。
- 人物最大 HP 一般 20。一只满状态的普通僵尸贴着你开始它的回合，能攻击 5 次、每次约 5 点伤害：**回合结束站在哪里，是最要紧的决定。**

### 规划器怎么算

- **回合结束风险**：对这回合走得到的每个格子，算出站在那里时，下个僵尸回合**整个队伍**预计掉多少血、有多大死亡风险。
  考虑的因素包括：
  - 哪些僵尸会来打谁（僵尸追最近的人）；
  - 能打几下：用僵尸自己算好的路线，行动力减去走路花的，再减去砸开路上关着的门窗花的；
  - 闪避，以及伤害减防御；
  - 抓伤 / 擒抱 / 咬的分布：取决于是否流血、剩多少 AP。

  死亡折算成 80 点 HP，血越少越怕挨打。**你的损失按 5 倍算**（你倒下游戏就结束）。
  队友站得比你离某只僵尸更近，它就改去追队友：满血、穿护甲的队友会主动替你挡，血少的不会。
- **一次攻击的收益**按「拆掉它多少威胁」算：
  - 头：这回合连续打头能打死它的概率；
  - 躯干：攻击力按比例下降；
  - 腿：行动力按比例下降。

  打掉的比例体现在回合结束风险里：它少打谁几下，打死了就不打了。
  另外加上削弱它的长远收益：下回合就能打到人的僵尸按 3.5 倍算；打不到任何人的只按 0.5 倍，
  因为它会自己走过来，把行动力花在走路上，下回合我们满 AP 先手。
  打死一只僵尸本身再加 2 点：躯干打到 0 的残废僵尸威胁算出来是 0，但它还会咬流血的人、
  挡着你们搜刮，不补刀的话整队会一直守着它（v1.1 在长时间测试里就是这样卡住的）。
- **武器磨损**也是代价：近战每打中一下掉 `6~8 × (1 − 耐久/13)` 点状态，打头 ×1.5，
  100 点的武器十来下就坏。每点按 0.02 HP 算，身上只剩这一把能用的时按 0.06 算。
- 每一步比较所有「目标 × 武器 × 部位 × 站位（原地或先走过去）× 打一下就走还是这回合打到底」：
  `收益 − 回合结束风险的变化 − 枪声引来僵尸的代价 − 子弹 − 武器磨损`，挑最高的。
  打头按「打死 / 没打死」两种结局分别算风险再按概率加权：打完知道结果、可以分别挑站位；
  也不会把「一半概率砍不死、0 AP 站在它旁边挨 5 下」的风险平均掉。
- 不划算就停手，最后站到风险最低的格子。

撤退、补刀、等僵尸过来、打完就跑、集火、救人、替你挡，都是这笔账算出来的结果，没有单独写规则。

### 实测：在真实存档上和原版对打

用游戏自己的代码离线加载存档（地图、人物、僵尸都是真的），把队伍放进有僵尸的地点，
原版 AI 和本 MOD 各带队打同样的场景（队友回合 + 真实的僵尸回合）。
每场 30 回合，每 3 回合从远处补 2 只僵尸；你这一方分三种：站着不动不还手、由原版 AI 操控（两边一样）、
由同一套 AI 托管（像用「AI 托管主角」MOD 时）。
调参用一批场景，下表是**另外 40 个没参与调参的场景**的合计：

| 你这一方 | 版本 | 击杀 | 队友阵亡 | 队友掉血 | 你阵亡 | 你掉血 |
|---|---|---|---|---|---|---|
| 站着不动 | 原版 | 238 | 9 | 285 | 0 | 8.7 |
| | v1.1 | 118 | 1 | 24 | 4 | 82 |
| | **v1.2** | **241** | **0** | **6** | **0** | **0** |
| 原版 AI 操控 | 原版 | 370 | 1 | 63 | 0 | 21.7 |
| | v1.1 | 353 | 0 | 8 | 1 | 27 |
| | **v1.2** | **366** | **0** | **20** | **0** | **18** |
| 一起托管 | 原版 | 360 | 1 | 76 | 0 | 21.7 |
| | v1.1 | 190 | 1 | 31 | 0 | 4 |
| | **v1.2** | **328** | **0** | **1.8** | **0** | **0** |

v1.1 只在 8 回合的短测试里验证过，拉长到 30 回合暴露了两个问题：
- 残废僵尸不补刀，整队守着它不动，僵尸越积越多（击杀只有原版一半）；
- 不算武器磨损，唯一带武器的队友几回合就把刀砍坏了，之后谁都打不了，站着的你被打死。

v1.2 补上了补刀价值、磨损代价和从队伍拿武器，击杀回到原版水平，挨打仍然远少于原版。

|---|---|---|
| 开枪 | 有枪就开 | 枪声会把附近最多 40 只没在追人的僵尸引过来，这个代价（每只约 0.8 HP）和子弹都算进收益 |
| 流血 | 照样贴着打 | 流血时 AP 被扣光会被咬死，这条直接算进死亡风险；会主动离开 |
| 杂事 | 僵尸在旁边也照样读书、制作、修东西 | 僵尸能打到自己时先不做，留着 AP（回合结束有 AP，部分攻击会变成只扣 AP 的擒抱） |
| 护甲 | 不会换衣服 | 把自己背包里有防御的衣物穿上（不脱任何东西），总负重不超过 9 |
| 武器 | 坏了就空手站着（原版没武器不攻击） | 没有能用的近战武器（没有、或状态都低于 10）时，从你和其他队友包里拿一把多余的：每人至少留一把，不拿你最好的那把和你的「最爱武器」。装了队伍背包共享时本来就能用大家的武器，不需要拿 |
| 回合结束 | 站在僵尸旁边结束回合 | 还有 AP 时换到风险最低的格子；站在门边、关门能明显少挨打就关门（0.5 AP） |
| 行动顺序 | 固定顺序 | 离僵尸近、正在交战的先行动，后面的人看着结果再决定 |
| 护卫 | 往你身边走，不管危险 | 按回合结束风险挑你附近的格子，不送上门 |

## 生存与协作

| | 原版 | 加强后 |
|---|---|---|
| 用药 | HP 低于 5 才吃药，挑最强的；强度超标时会给玩家弹「会昏厥」确认框 | HP 低于 50% 就治疗，药物强度不超过头痛线（9）；HP 低于 25% 时放宽，但永远不到昏厥线（20） |
| 治疗别人 | 不会 | 给相邻或走得到的你和其他队友包扎、用药，流血的先治；医生会用「急救」。不会为此走进僵尸攻击范围 |
| 护卫 | 有僵尸靠近你时照样去搜刮、修东西 | 僵尸进入你周围 8 格内时，队友放下搜刮、升级、清障、修车、种田，先回到你身边 |
| 捡东西 | 默认只捡价值「高」以上、重量 1.5 以下的（弹药每发价值 2、绷带 13、药 13，都不捡） | 另外捡用得上的：队伍里有对应武器的弹药和箭、药品绷带、比手上明显更好的近战武器 |
| 你丢的东西 | 值钱的会被队友捡回去 | 你和队友拿过的东西放在地上就不捡 |
| 远处的东西 | 一回合走不到就站着不动；只比较最近 6 个格子 | 先走一段，下回合接着捡；比较最近 12 个格子；不进僵尸攻击范围 |
| 搜刮范围 | 只搜你附近：跟随 20 格内、靠近 5 格内 | 同伴AI设置里可以打开「搜刮整个地点」（默认关），见下一节 |

### 搜刮整个地点（可选，默认关）

在游戏的「同伴AI设置」里，「搜索」下面多了一行「搜刮整个地点」（每个队友单独设置；「搜索」关着时变灰）。打开后：

- 队友不只搜你附近，而是把当前地点各层没搜过的家具（和尸体，看「搜尸体」开关）、地上符合拾取设置的东西都搜一遍；
  一回合走不到就先走一段，下回合接着。
- 几个队友都打开时会分头：别人已经要去的地方附近，后行动的队友换个地方搜。
- 有僵尸进入你周围 8 格时照样先回到你身边护卫；在外面搜刮的这一回合，不会被「回合结束离你太远」的代价拉回来。
- 背的东西让走一格多花 0.5 AP（力量 10 时大约背了 65 公斤）就不再去搜新的地方，改回普通的搜索范围。
- 搜到的东西留在队友自己包里（装了队伍背包共享时全队都能用）。基地安全时和原版一样只搜室外。
- 地点之间的移动还是你带队，队友不会自己去别的地点。

实测（真实存档，军事基地 103 个家具，你站着不动，队友 30 回合；离线环境）：

| | 没有僵尸：搜完的家具 | 第 8 回合起每 2 回合来 3 只僵尸（6 局平均） | 队友阵亡 / 掉血（6 局合计） |
|---|---|---|---|
| 不开 | 80 / 103 | 77.2 / 103 | 0 / 0 |
| 打开 | 103 / 103 | 86.0 / 103 | 0 / 2.8 |

小地点（商店、药店）原版的 20 格范围本来就够，开不开一样。有僵尸看得见时队友本来就不去搜刮，
所以战斗中开不开也一样（30 回合长测 20 个场景，结果完全相同）。

## 配置

编辑 `companion_ai.py` 开头的常量，改完重启游戏生效：

- `PLANNER`：回合规划开关（关掉就回到原版攻击流程，只保留选目标 / 武器 / 部位）
- `PROTECT_PLAYER_WEIGHT` / `PROTECT_TEAM_WEIGHT`：你 / 其他队友的损失按几倍算，默认 `5` / `1`
- `FUTURE_WEIGHT` / `FUTURE_WEIGHT_IDLE`：削弱僵尸的长远收益（下回合能打到人 / 打不到人的），默认 `3.5` / `0.5`
- `POTENTIAL_CAP`：单只僵尸每回合威胁的上限，默认 `12`
- `CLEAR_VALUE`：打死一只僵尸本身值多少 HP（让队友给残废僵尸补刀），默认 `2`
- `WEAR_COST` / `WEAR_COST_LAST`：武器每掉 1 点状态折算成多少 HP（有备用 / 只剩这一把），默认 `0.02` / `0.06`
- `ARM_FROM_PARTY`、`ARM_MIN_CONDITION`：没武器时从队伍拿一把；状态低于多少算不能用，默认 `10`
- `COMMIT_PLANNING`：评估时也考虑「这回合打到底」
- `CLOSE_DOORS`：回合结束时关门挡僵尸
- `ORDER_COMPANIONS`：离僵尸近的队友先行动
- `DEATH_COST`、`ZOMBIFY_COST`：死亡 / 被咬尸变折算成多少 HP，默认 `80` / `25`
- `RISK_AVERSION`：血越少越怕挨打的程度，默认 `1.0`
- `STAY_NEAR_COST`：回合结束时离你每远一格的代价，默认 `0.15`
- `MOVE_AP_COST`、`MIN_ATTACK_GAIN`、`MIN_REPOSITION_GAIN`：走位的 AP 代价、出手 / 换位置的最低收益
- `QUIET_COMBAT`、`NOISE_COST_PER_ZOMBIE`、`AMMO_COST`：安静作战；每引来一只僵尸、每发子弹的代价
- `COMBAT_LOCK`：僵尸能打到自己时不做杂事
- `AUTO_DRESS`、`DRESS_MAX_ENCUMBRANCE`：自动穿护甲、负重上限
- `SAFE_STEP`：回合结束前换到更安全的格子
- `HEAL_HP_RATIO` / `CRITICAL_HP_RATIO`：用回血药 / 濒危的 HP 比例，默认 `0.50` / `0.25`
- `MED_STRENGTH_SOFT` / `MED_STRENGTH_HARD`：平时 / 濒危时允许的药物强度上限，默认 `9` / `19`
- `HEAL_OTHERS`、`HEAL_OTHERS_MAX_MOVE_AP`：是否给别人治疗、最多走多少 AP 过去
- `GUARD`、`GUARD_RANGE`、`GUARD_STAY_WITHIN`：护卫开关、触发距离、离你多远才往回走
- `PICK_UP_NEEDED`：额外捡用得上的东西；`PICK_UP_AMMO` / `PICK_UP_MEDS` / `PICK_UP_BETTER_MELEE` 分项开关
- `BETTER_MELEE_RATIO`：地上的近战武器比手上最好的强多少倍才捡，默认 `1.25`
- `PICK_UP_NAMES`：额外总要捡的物品内部名，例如 `("tape", "nails")`
- `PICK_UP_MAX_WEIGHT`：单件比这重的不额外捡，默认 `3.0`
- `KEEP_DROPPED`：不捡回你们自己丢下的东西
- `SEARCH_APPROACH`、`SEARCH_CANDIDATES`：走不到时先走一段；每次比较多少个目标格
- `SWEEP_LOCATION`：在同伴AI设置里加「搜刮整个地点」开关（`False` = 不加）；`SWEEP_MAX_SLOWDOWN`：背的东西让走一格多花多少 AP 时停，默认 `0.5`
- `LOG_DECISIONS`：把每次决策写进 `companion_ai.log`

## 安装 / 卸载

- 创意工坊：<https://steamcommunity.com/sharedfiles/filedetails/?id=3826759381>，订阅后在下载目录双击 `install.bat`（不需要 Python）。
- 从源码：双击本文件夹的 `install.bat`（需要 Python 3.12，脚本会自动用 uv 或 py 启动器）。
- 卸载：双击 `uninstall.bat`。如果 AI 托管等其他 MOD 还在，只会停用本 MOD（生成 `DISABLED` 文件），
  然后删除本文件夹即可；否则会还原 `base_library.zip`。
- **游戏更新后**：Steam 会覆盖 `base_library.zip`，MOD 会失效，重新运行一次 `install.bat` 即可。
- 为了认出「你们丢下的东西」，MOD 会给你和队友拿过的物品加一个 `_companion_ai_owned` 记号，随存档保存；
  卸载后不起作用，存档照常可用。

## 原理

和 AI 托管、队伍背包共享共用 `base_library.zip` 里的 V2 MOD 加载器（见上一级 README）。
加载器在 `actions.compaction` / `core.creature.character` / `core.constants` / `ui.modals.compautomodal` 加载后调用本 MOD，替换这些函数：

- `compaction.companion_action` → 先按交战程度排好队友的行动顺序，再走原版（行动完恢复原来的顺序）
- `compaction.handle_attack` → 有看得见的僵尸时用回合规划；只有敌对 NPC 或 DLC 时交给原版攻击流程
- `compaction.move_closer_to_player` → 修原版 bug：队友一步都走不了时原版对空列表取 `min()` 报错，中断整个队友回合
- `compaction.get_closest_target` / `get_weapon` / `move_and_attack`、`character.process_attack`（模块全局）
  → 原版攻击流程里也按同样的效果模型挑目标、武器、部位；玩家自己的攻击不受影响
- `compaction.flee`、`compaction.handle_food_consumption` → 换到风险最低的格子、需要时关门（之后照常吃东西）
- `compaction.handle_medication` → 穿护甲、没武器时从队伍拿一把、自己和别人的治疗
- `compaction.get_filtered_pickup_items_for_cell` → 原版按价值 / 重量设置筛出的东西，去掉你们丢的，加上用得上的
- `compaction.handle_search_or_pickup` → 流程照原版（走到最近的目标格，捡东西、搜家具 / 尸体，循环到 AP 不够），加上上面的改动
- `compaction.check_search_or_pickup`、`compaction.get_follow_zone` → 打开「搜刮整个地点」的队友在判断 / 执行搜刮时，范围是整个地点；
  升级、睡觉等其他用到跟随范围的地方照原版
- `core.constants.DEFAULT_AUTOMATION_SETTINGS` 里加 `sweep_location: False`：读档时游戏按默认设置的键整理每个人的设置，
  不加的话这个开关读档后会被删掉；卸载 MOD 后游戏读档时会自己把它去掉
- `CompAutoModal.setup` → 在「搜尸体」下面插入这个开关（文字和鼠标提示随游戏语言：简体、繁体、其他语言用英文）
- 读书、制作、修理、升级、清障、修车、种田等花 AP 的任务 → 僵尸能打到自己时跳过
- 搜刮、升级、清障、修车、种田 → 再套一层护卫判断（按回合结束风险挑你附近的格子）

DLC 战役里有原版攻击流程才处理的任务判定和特殊角色，所以 DLC 中不用回合规划，只用选目标 / 武器 / 部位。

每个替换都有兜底：出错时把错误写进 `companion_ai.log`，改用原版逻辑。

## 排错

正常启动后 `companion_ai.log` 里应有：

