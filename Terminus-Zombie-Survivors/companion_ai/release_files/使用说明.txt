Terminus: Zombie Survivors - 队友 AI 加强 MOD（非官方）
=====================================================

在游戏自带的队友 AI 上替换几个做决定的环节，其余保持原版。
尊重游戏原生的「队友自动化设置」：攻击开关、是否用枪、是否使用医疗用品、是否拾取物品、移动方式等。
「AI 托管主角」MOD 控制主角时同样生效。

【为什么要手动安装】
游戏的创意工坊模组只支持数据（JSON/图片），不会执行代码。本 MOD 需要运行一次安装程序，
订阅后游戏内模组管理器里的开关对它无效，以下面的安装 / 卸载为准。

【安装】（不需要装 Python）
◆ 从创意工坊订阅的：
  1. 订阅后等 Steam 下载完成，先退出游戏。
  2. 打开 MOD 下载目录：
       <你的 Steam 库>\steamapps\workshop\content\1534980\__ITEM_ID__
     最快的找法：在游戏目录（Steam 库里右键游戏 → 管理 → 浏览本地文件）向上退两级到 steamapps，
     再进 workshop\content\1534980，里面带 install.bat 的那个文件夹就是。
  3. 双击 install.bat，看到“安装完成”即可。
◆ 下载压缩包的：解压到任意位置，双击 install.bat。

安装程序会自动找到游戏（找不到会弹窗让你选游戏目录），把 MOD 复制到 <游戏目录>\companion_ai，
并先校验游戏版本，不匹配就不会改动任何游戏文件。

【效果】
战斗：回合规划
- 队友按游戏真实规则算账：回合结束站在哪个格子，下个僵尸回合整个队伍会挨多少打、有多大死亡风险
  （僵尸追最近的人、能打几下、砸门要花的行动力、闪避、伤害减防御、流血且 AP 为 0 会被咬死）。
  你的损失按 5 倍算，因为你倒下游戏就结束。
- 每一步比较打哪只、用什么武器、打哪个部位、要不要先走过去、打一下就走还是这回合打到底，
  收益和风险都折算成 HP；不划算就停手，最后站到风险最低的格子。
- 由此而来：撤退、等僵尸走过来再先手、打完就跑、集火、救人；满血穿护甲的队友会站到僵尸和你之间替你挡，
  血少的不会。
- 打哪个部位：头 = 打死的概率；躯干 = 攻击力按比例下降（打到 0 就不能抓人）；腿 = 行动力按比例下降。
- 残废的僵尸（没了躯干不能抓人，但还会咬流血的人）也会补刀清掉，不会整队守着它不敢干别的。
- 武器磨损算进代价（近战打中一下掉 6~8 点状态，打头更多），不为一点点收益把武器磨坏。
- 没有能用的近战武器时，从你和其他队友包里拿一把多余的：每人至少留一把，不拿你最好的那把和你的最爱武器。
- 开枪会把附近最多 40 只僵尸引过来，这个代价算进收益里，近战或弓够用时不开枪。
- 站在门边、关门能明显少挨打就关门；离僵尸近的队友先行动，后面的人看着结果再决定。
- 僵尸能打到自己时不读书、制作、修理，留着 AP；自动穿上自己背包里有防御的衣物。
- 修了原版一个 bug：队友一步都走不了时，原版会报错、中断整个队友回合。

实测（在真实存档上和原版各带队打同样的场景，每场 30 回合、不断有新僵尸过来；
40 个没参与调参的场景合计）：
  你站着不动不还手时：原版队友阵亡 9 次、掉血 285、你掉血 8.7；本 MOD 队友阵亡 0、掉血 6、你掉血 0。
  你由 AI 托管时：原版队友阵亡 1 次、掉血 76、你掉血 21.7；本 MOD 队友阵亡 0、掉血 1.8、你掉血 0。
  击杀数和原版差不多。

生存与协作
- 用药：HP 低于 50% 就治疗，药物强度不超过头痛线；濒危时放宽，但永远不到昏厥线。
  （原版 HP 低于 5 才吃药，强度超标时还会给玩家弹「会昏厥」确认框）
- 互相治疗：给身边或走得到的你和其他队友包扎、用药，医生会用「急救」。不会为此走进僵尸攻击范围。
- 护卫：僵尸进入你周围 8 格内时，队友放下搜刮、升级、清障、修车、种田，先回到你身边。
- 拾取：原版默认只捡价值「高」以上的东西，弹药、绷带、药都不够格。现在另外会捡
  队伍里有对应武器的弹药和箭、药品绷带、比手上明显更好的近战武器；
  不捡回你们自己丢下的东西；一回合走不到的先走一段，下回合接着捡；不进僵尸攻击范围。
- 搜刮整个地点（可选，默认关）：游戏「同伴AI设置」里「搜索」下面多了一行「搜刮整个地点」，
  每个队友单独开。原版队友只搜你附近（跟随 20 格内、靠近 5 格内）；打开后队友把当前地点各层
  没搜过的家具（和尸体，看「搜尸体」开关）、地上符合拾取设置的东西都搜一遍，几个队友分头搜。
  有僵尸靠近你时照样先回来护卫；背的东西让走一格多花 0.5 AP（力量 10 约 65 公斤）就不再去搜新的地方。
  搜到的东西留在队友自己包里。队友不会自己去别的地点。
  实测（军事基地 103 个家具）：没有僵尸时不开搜了 80 个、打开 103 个全搜完；中途不断来僵尸时
  平均 77 个 → 86 个，6 局合计队友只多掉了 2.8 血、没有阵亡。小地点开不开一样。

【设置】
用记事本打开 <游戏目录>\companion_ai\companion_ai.py，改开头的数值，重启游戏。常用的：
  PROTECT_PLAYER_WEIGHT = 5   你的损失按几倍算（越大队友越拼命护你）
  RISK_AVERSION = 1.0         血越少越怕挨打的程度
  HEAL_HP_RATIO = 0.50        开始用回血药的 HP 比例
  GUARD = True                护卫；GUARD_RANGE = 8 触发距离
  QUIET_COMBAT = True         不乱开枪
  ARM_FROM_PARTY = True       没武器时从队伍拿一把多余的
  PICK_UP_NEEDED = True       额外捡用得上的东西
  SWEEP_MAX_SLOWDOWN = 0.5    搜刮整个地点时，背到走一格多花这么多 AP 就停
  KEEP_DROPPED = True         不捡回你们丢下的东西
  LOG_DECISIONS = True        把每次决策写进日志
每一项的含义都写在文件里。

【怎么看它在做什么】
<游戏目录>\companion_ai\companion_ai.log 里每次决策一行，例如：
  XX 用 斧头 打 僵尸 的头部（收益 6.3，回合结束预计损失 0.5）
  XX 回合结束前换到更安全的位置（预计损失 13.3 → 0.1）
  XX 关上门挡僵尸（预计损失 6.2 → 1.0）
  XX 手上没有能用的武器，从 YY 包里拿了 军刀
  XX 捡起 弹药 ×3、绷带
  XX 搜刮整个地点：去下一处，这回合先走一段

【MOD 更新后】
创意工坊更新了 MOD 后，再双击一次 install.bat，把新文件复制进游戏。

【游戏更新后】
Steam 更新游戏可能会还原被修改的文件，导致 MOD 失效，再双击一次 install.bat 即可。
如果提示“Python 运行库不匹配”，说明游戏升级了内置 Python，需要等 MOD 更新。

【卸载】
双击 uninstall.bat（删除 <游戏目录>\companion_ai；没有其他 MOD 在用时游戏会恢复原样），然后取消订阅。
为了认出「你们丢下的东西」，MOD 会给你和队友拿过的物品加一个记号，随存档保存；
卸载后这个记号不起任何作用，存档照常可用。「搜刮整个地点」开关卸载后读档时游戏会自己去掉。

【原理与说明】
安装程序只修改一个文件：<游戏目录>\_internal\base_library.zip 里的 Python 标准库 linecache.pyc，
换成“原样执行原代码 + MOD 加载器”的版本。MOD 加载器与「AI 托管主角」「队伍背包共享」等 MOD 共用，
可以同时安装；安装包自带原始文件，最后一个 MOD 卸载时用它还原。
MOD 源码（companion_ai.py）是明文，可以直接查看。单机游戏。
每个替换都有兜底：出错时改用原版逻辑，错误写在 companion_ai.log，反馈问题时请附上。
